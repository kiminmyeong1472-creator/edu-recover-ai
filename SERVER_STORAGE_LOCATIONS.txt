3. 소스 저장
- 현재 빌드 원본: private GitHub repository kiminmyeong1472-creator/edu-recover-ai
- 실행 위치: Railway edurecover-prod container
- 현재 Railway는 위 private repository에서 빌드하므로 "Railway 서버에만 유일본이 존재한다"고 주장하지 않는다.

4. 출제·검증 런타임 자산
- runtime path: app/authoring_assets/
- loader: app/services/authoring_assets.py
- 포함: 정규화 어휘, 학년별 검증 어휘, 구체 구문, 학년별 구문난도, 영어 출제·검수 규칙, 출제마법사 기준, 오답설계 규칙, 현재정책
- 외부 AI에는 전체 코퍼스가 아니라 현재 작업에 필요한 최소 발췌만 전달한다.

5. 라우터·게이트·AI 통제
- owner/provider gate: app/services/control_plane.py
- provider-retention/ZDR fail-closed gate: app/services/privacy_guard.py
- provider access notice: app/services/access_notice.py
- provider-isolated generation channels: /channel/<provider>/generate
- provider-isolated verification channels: /channel/<provider>/verify

6. 비밀값
- API key values: Railway service environment variables only
- 채팅/출제지침/상태 API/소스문서에 실제 키 값을 기록하지 않는다.

7. ZDR
- EDURECOVER_REQUIRE_ZDR=true일 때 provider-side ZDR/retention coverage가 명시적으로 확인되지 않은 채널은 HOLD한다.
- 확인 플래그는 실제 계약/조직·프로젝트 설정/승인 확인 후에만 true로 설정한다.
- 앱의 store=false 또는 stateless 호출만으로 provider-side ZDR을 보장했다고 표시하지 않는다.

8. Google Drive
- Drive 원본 루트: 교육플랫폼_비공개_마스터DB_영업비밀 / ID 1NYmOs9DRluSSbHeM568FDDEuA94MntuT.
- 2026-09-26 재귀 인벤토리 기준: 고유 폴더 17개, 고유 파일 177개를 manifest에 식별하였다.
- 실제 서버 빌드소스에 내용이 설치된 파일: 기존 curated 15개 + drive_archive 67개 = 82개.
- drive_archive 경로: app/private_assets/drive_archive/ . 모든 archive 파일은 provider_policy=never_send이다.
- manifest 경로: app/private_assets/drive_archive_manifest.json .
- root 직접 파일 76개 중 72개는 curated/archive로 내용 보존되었고, 채팅백업·구소스 ZIP 등 4개는 PENDING_SECRET_SCAN으로 내용 반입을 보류했다.
- 대용량 암호화/라이브러리 백업과 중복·과거자료는 Drive ID·크기·분류를 manifest에 보존하되, 실행 Git 저장소 비대화를 피하기 위해 REFERENCE_ONLY 상태로 구분한다.
- owner-only /owner/authoring-assets에서 archive 요약과 설치 파일의 런타임 SHA-256을 확인할 수 있다.
- 외부 AI에는 drive_archive 원문을 직접 전달하지 않는다. provider_policy=excerpt_only로 별도 승인된 curated 자산만 현재 작업에 필요한 발췌 범위로 1회성 전달한다.
- 비밀번호/암호를 우회하거나 해제하는 기능은 사용하지 않는다.
- 따라서 "Google Drive 전체 바이트 완전복제" 또는 "Railway 영속볼륨 유일본"이라고 주장하지 않는다. 현재 보존 증거는 private GitHub 빌드소스 및 그로부터 생성되는 Railway 배포 이미지 기준이다.
