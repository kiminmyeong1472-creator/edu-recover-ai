# 사용자 작업 우선순위 고정

상위 지시를 준수하면서 사용자가 직접 정한 순서·선행조건·후속 작업을 유지하십시오.

## 공통 규칙

1. 현재 목표, 우선순위, 선행조건과 보류한 후속 작업을 기존 지시에서 확인하십시오.
2. 편의, 비용 조사, 추천 모델, 다른 도구나 작업자의 계획을 이유로 순서를 바꾸지 마십시오.
3. 사용자가 직접 바꾼 최신 지시는 반영하십시오. 단순 진행·재시도를 기존 조건 삭제로 해석하지 마십시오.
4. 지시 사이에 실제 충돌이 있으면 두 지시와 바뀌는 결과를 짧게 제시하고, 해당 부분은 실행 전에 사용자에게 확인하십시오. 충돌하지 않는 작업은 계속하십시오.
5. 일상적인 구현 선택이나 이미 승인된 일에 불필요하게 재확인을 요구하지 마십시오. 침묵이나 시간 경과를 승인으로 취급하지 마십시오.
6. 목록 등록, 허용 근거 저장, 주소 연결, 실제 응답 수신과 운영 반영을 구별하십시오. 연결했다고 해서 반드시 호출에 성공하는 것은 아닙니다.
7. 다른 창에 직접 게시할 수단이 없으면 전체 창에 전달했다고 말하지 마십시오. 공통 스킬 저장, 이 창 공지와 실제 전달한 대상만 보고하십시오.

## 2026년 10월 17일 고정 작업 순서

사용자 지시 원문:

> 앤비디아 없는모델3종 중 기장 좋은 모델은,   모든착업들이 끝난 후  내  개인계정으로불러오도록 저장. 우선순위 절대바꾸지 않고 충돌시 사용자에게 확인하는 스킬 작업지침으로 고정. 공지.
>
> 일단 27개부터 다 불러오는 작업 진행. 그런데 딥인프라와 투게더가 뭐야?

1. **지금은 27개 모델을 모두 불러오는 작업부터 진행하십시오.** 원래 25개에 Qwen3-32B와 DeepSeek-V3.2를 포함한 27개를 빠뜨리지 마십시오.
2. **경쟁 모델 개발·학습 제한이 없는 경로 확보를 우선하십시오.** 무보관(ZDR: 적용 계약·기능 범위에서 요청·응답 내용을 저장하지 않는 정책)은 후순위로 검토하되 두 조건을 함께 충족하는 확인된 경로가 있으면 우선 사용하십시오.
3. 외부 호출 업체의 계약과 모델 파일의 사용허가를 각각 확인하십시오. 무보관이나 출력 소유만으로 경쟁 모델 학습 허용을 단정하지 마십시오.
4. 기존 OpenRouter 경로를 보존하십시오. 새 호출 경로 추가를 기존 경로 삭제나 자동 대체로 바꾸지 마십시오.
5. 원래 모델 이름·버전·수치 정밀도를 보존하십시오. 다른 모델·날짜 버전·양자화 변형으로 바꾸어야 지시를 수행할 수 있다면 차이를 밝히고 사용자에게 확인하십시오.
6. **NVIDIA 3종 중 선택한 모델을 개인 계정에서 실행하는 일은 모든 작업이 끝난 뒤의 후속 작업으로만 저장하십시오.** 앞으로 당겨 실행하지 마십시오.
7. 종합 추론과 복잡한 작업 능력을 우선하는 후속 후보로 **NVIDIA-Nemotron-3-Super-120B-A12B-BF16**을 기록하십시오. 공식 공개 성능·규모를 바탕으로 정한 후보이며 사용자 과제에서 실측 최고 성능을 확인했다고 표현하지 마십시오. 후속 실행 시 정확한 가중치·장비·비용과 개인 계정을 확인하십시오.
8. 불러오지 못한 모델은 정확한 이름과 이유를 남기고 독립적으로 진행할 수 있는 연결 작업을 계속하십시오. 빠진 모델을 목록에서 삭제하지 마십시오.
