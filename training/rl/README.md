# 검증된 저순위 후보를 다음 탐색에 반영하는 CPU 정책 학습

이 디렉터리는 별도로 명령을 실행하는 연구용 경로다. 운영 교사 API와 후보 탐색 화면은 이 가중치 학습을 호출하지 않는다. 운영에서는 현재 유효한 검증 영수증의 사례 통계와 승인된 규칙만 다시 계산하며, 근거 철회 시 해당 사례를 제외한다. 생성 신경망의 자기훈련 또는 외부 기초 모델의 재훈련을 운영 완료 기능으로 표시하지 않는다.

이 모듈은 후보를 다시 탐색할 때 쓸 작은 선택 정책의 가중치를 실제로 학습한다. GPT 등 기초 모델의 가중치를 학습하는 모듈은 아니다.

## 입력과 검증

- 후보의 원래 순위와 모델 점수는 변경하지 않고 원본 기록에 남긴다.
- 예측 입력에는 탐색 전에 기록한 `hypothesis_type`, `concept_refs`, `context_ref`만 사용한다. 원래 순위·모델 점수·정답 판정·사후 사유를 예측 입력으로 사용하지 않는다.
- 정답 또는 기각 결과가 확인되고, 그 이유가 교사에게 확인되고, 학습 사용과 사용권이 승인된 현재 유효 표본만 학습한다.
- `UNKNOWN`, 무효화, 학습 미승인, 사용권 미확인 자료는 제외한다. 보상 0 또는 오답 -1로 바꾸지 않는다.
- 결과가 맞고 왜 맞았는지 확인된 후보의 내용 특성에 +1 보상을, 기각 이유가 확인된 후보에 -1 보상을 연결한다. 순위가 14위라는 이유로 보상을 추가하지 않는다.
- 사후 이유는 후보 가설과 보상이 확인됐다는 근거다. 이유의 원문은 영수증과 학습 표본에 보존되고, 정책 상태에는 이유 해시가 남는다. 사후 이유를 미래 예측에 넣는 데이터 누출은 허용하지 않는다.
- 같은 문항 가족을 `TRAIN`과 `EVAL` 양쪽에 넣으면 중단한다. 평가 표본은 가중치를 변경하지 않는다.
- 현재 유효한 전체 학습 자료로 매번 다시 계산하므로, 무효화된 보상이 이전 가중치에 남지 않는다.

SHA-256은 파일 변경을 확인하기 위한 것이다. 제출자가 새 해시를 만들 수 있으므로, 독립 실행기의 해시 검사는 사용자 인증이나 정답의 진실성 증명이 아니다. 운영 API가 권한과 원자료·검증 기록의 연결을 먼저 확인한다.

## 실제 학습 계산

검증 완료 후보끼리 하나의 비교 묶음을 구성한다. 각 후보의 내용 특성을 `x_i`, 정책 가중치를 `w`, 확인된 보상을 `r_i`라 둔다.

`p_i = softmax(w · x_i)`

`J = Σ p_i r_i`

`∇J = Σ p_i (r_i − J) x_i`

위 기울기를 CPU에서 계산하고 가중치에 더한다. 모든 후보를 차례로 열거한 기존 기록에는 실제 무작위 선택 확률이 없다. 따라서 이 학습을 선택 확률을 필요로 하는 오프라인 REINFORCE나 PPO라고 부르지 않는다. 확인된 비교 묶음에 대한 기대보상 정책 기울기 계산이다. 확인된 후보가 하나뿐이면 상대적인 선호를 학습할 수 없어 가중치를 갱신하지 않는다.

`policy_priority`는 다음 탐색의 우선도다. 정답일 확률이 아니며, 높은 우선도가 교사 검증을 대신하지 않는다.

## 재현 실행

```bash
python3 -m unittest tests.test_ranked_candidate_policy -v
python3 -m training.rl.demo_ranked_candidate_policy --output /tmp/ranked_policy_demo.json
python3 -m training.rl.ranked_candidate_policy export.json --output policy.json --context-ref TASK_CONTEXT
```

데모는 실제 학생 자료가 아닌 명시적인 합성 자료다. 학습에서는 14위의 항 개수 누락 가설을 채택하고 1위의 마지막 항 오용 가설을 기각한다. 평가에서는 채택한 내용의 가설을 9위에, 기각한 내용의 가설을 14위에 놓는다. 30회 계산 후 내용이 맞는 후보의 탐색 우선도가 0.5에서 약 0.9682로 올라간다. 잘못된 14위 후보는 약 0.0318로 내려간다. 이는 특정 순위에 보너스를 주지 않는다는 재현 검증이며, 학생 학습 효과나 LLM 정확도 개선을 측정한 결과가 아니다.
