# NVIDIA 직접 운영 준비 상태

2026-10-17 기준, 원래 25개와 Qwen3-32B·DeepSeek-V3.2를 포함한 27개 연결이 우선입니다. NVIDIA 개인 계정 실행은 모든 기존 작업이 끝난 뒤로 보류합니다. 후속 종합 추론 후보는 Super 120B BF16이며 사용자 과제에서 최고 성능을 실측한 것은 아닙니다.

Nano 4B BF16를 사용자 GPU 서버에서 시험 실행할 준비 구성을 `deployment/nvidia/nano4b/`에 추가했습니다. 실제 서버 생성·결제·GPU 구동·유료 추론 검사는 수행하지 않았습니다.

사용자는 모든 모델의 ZDR 가능 경로와 요금 조사를 김대표 창에 인계하고 이 창에서는 NVIDIA부터 직접 운영하도록 요청했습니다. 이 구성은 그 실행 준비에 해당하며 ZDR이나 한국어 성능을 확인한 결과가 아닙니다.

고정된 NVIDIA 공식 가중치·토크나이저·코드 버전, parser 해시 검사, 인증 필수, HTTPS, 모델 포트 비공개, 요청·응답·접근 로그 비저장 구성을 포함합니다. Chutes에서 제공하는 다른 NVIDIA 모델을 선택 모델인 것처럼 대체하지 않습니다. 전용 토큰 이름은 `EDURECOVER_NEMOTRON_API_KEY`입니다.

GPU 제공자 계정·서버·비용·실제 도메인·전용 키를 확정하고 실행 검사를 마쳐야 운영 완료가 됩니다. 자세한 준비 조건과 공식 근거는 [운영 안내](../deployment/nvidia/nano4b/README.md)에 있습니다.

이 변경은 검토용 작업 가지에만 저장하며 운영 서비스에 적용하거나 기능을 활성화하지 않습니다. Nano 시험 준비를 NVIDIA 최종 선택 또는 우선순위 변경으로 해석하지 않습니다. 공유 지침: `AGENTS.md`, `.codex/skills/preserve-user-work-priorities/SKILL.md`.
