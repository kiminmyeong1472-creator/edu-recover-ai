# 뉴스·강의 음성·영상 전사

이 기능은 관리자 화면 `/owner/media`에서 파일을 받거나 마이크로 녹음한 음성을 받아 글로 옮깁니다. 영상은 일정 간격으로 뽑은 화면에서 자막·판서·슬라이드 글자를 읽습니다. 영상 속 물체·행동·장면의 의미를 알아내는 기능은 포함하지 않습니다.

## 처리 범위

- 음성을 글로 옮기는 기능(ASR): 지정한 유료 제공자의 `/audio/transcriptions` 형식 주소를 호출합니다. 주소·모델·키를 임의 선택하거나 다른 업체의 키를 재사용하지 않습니다.
- 화면 글자를 읽는 기능(OCR): 서버에서 Tesseract와 한국어·영어 인식 자료를 사용합니다. 기본 최대 24개 화면을 읽으며, 읽은 시각을 표시합니다. 전체 화면 변화나 모든 글자를 읽었다고 표시하지 않습니다.
- 분석: 원문에서 자주 나온 단어, 수치가 든 발언, 중요한 구절을 시간·출처와 함께 뽑습니다. 뉴스의 사실 확인이나 생성형 요약·강의 정답 판정은 수행하지 않습니다.
- 결과: 전사문 TXT, 구조화 자료 JSON, 순번형 자막 SRT, 웹용 자막 VTT. 음성 제공자가 문장별 시간을 주지 않으면 음성 조각 단위의 대략적인 시간을 표시합니다.
- 영상에 음성이 없으면 화면 글자만 처리합니다. 음성 처리 실패 후 읽은 화면 글자가 있으면 일부 처리 결과와 실패 이유를 함께 보존합니다.

## 기존 앱에 넣기

`app/services/media_core.py`, `media_jobs.py`, `media_api.py`, `media_workspace.html`을 같은 디렉터리에 넣으십시오. 공식 저장소의 `app/main.py` 변경에는 기능 연결, 시작·종료 시 작업 관리, 관리자 메뉴 링크가 포함돼 있습니다. 기존 로그인과 모델 목록은 보존했습니다.

다른 프로그램에 기능을 요청하는 연결 방법(API)은 모두 관리자 인증을 요구합니다. 파일 제출은 전송 동의와 전용 요청 표시를 함께 요구합니다. 공개 뉴스 주소 다운로드나 외부 재생목록은 받지 않습니다.

## Railway에 반영할 때

실행 환경 준비 파일 `deployment/media/Dockerfile`은 기존 앱과 함께 영상 변환기 FFmpeg, 화면 글자 인식기 Tesseract, 한국어·영어 인식 자료를 설치합니다. Railway의 설정 파일 경로를 `/deployment/media/railway.json`으로 지정해 이 준비 파일을 사용하십시오. 기존 공식 운영 서비스와 영속 볼륨을 그대로 사용하십시오. 새 프로젝트를 만드는 명령은 포함하지 않았습니다.

`deployment/media/media.env.example`은 설정 이름과 기본값을 제공합니다. `MEDIA_ASR_ENDPOINT`에는 제공자의 전체 HTTPS 호출 주소, `MEDIA_ASR_MODEL`에는 실제 모델 식별자, `MEDIA_ASR_API_KEY`에는 발급된 키 원문을 저장하십시오. 키를 16진수로 바꾸거나 특정 길이로 강제하지 않습니다. 줄바꿈만 잘못된 인증 헤더를 막기 위해 거부합니다.

요청·응답 무보관(ZDR)은 제공자의 해당 유료 계정·주소·제품에 적용되는 정책으로 확인해야 합니다. `MEDIA_ASR_DATA_POLICY_ACK=true`는 운영자가 이를 확인했다는 앱 설정이며, 제공자의 무보관 정책 자체를 증명하지 않습니다. 설정 확인 전에는 외부 음성을 보내지 않습니다. 파일마다 사용자의 전송 동의도 받습니다.

기본 한도는 파일 128MiB, 길이 2시간, 해상도 3840×2160, 대기·진행 중 작업 합계 2건입니다. 파일 크기 한도를 넘는 고화질 장시간 영상은 나눠 제출해야 합니다. 처리용 저장 공간은 최대 350MiB를 기준으로 제출을 제한하므로 기존 500MB 볼륨에 다른 자료가 많으면 제출이 거부될 수 있습니다. 결과는 24시간 후 정리하며, 처리한 원본은 즉시 삭제합니다. 결과를 보존하려면 만료 전에 내려받으십시오.

서버가 재시작되면 처리 중이던 작업을 중단으로 표시합니다. 유료 음성 요청을 자동 재실행하지 않습니다. 사용자가 파일을 다시 제출해야 합니다.

## 확인 상태

코드 실행 검사와 실제 FFmpeg·Tesseract 영상 글자 인식은 별도 시험 기록에 남깁니다. 음성 제공자 대체 응답으로 검사한 것은 실제 제공자 호출 성공으로 표시하지 않습니다. Railway 연결은 재인증 오류로 차단돼 이번 작업에서 운영 서버를 수정하지 못했습니다. 배포와 실제 외부 음성인식 응답 수신은 별도 확인이 필요합니다.
