# 기존 27개를 보존한 Chutes 9개 별도 직접 호출

2026-10-17 소유자가 지정한 2순위 작업으로 Chutes의 9개 제공판을 별도로 등록합니다.
제공판은 같은 계열이라도 버전·날짜·수치 정밀도가 다른 모델입니다. 기존 27개 목록,
OpenRouter 연결과 모델 개발·학습 허용 모음은 보존합니다. 연결했다고 해서 반드시
호출에 성공하는 것은 아닙니다. 이 문서는 연결 코드와 공개 목록 대조를 설명하며,
실제 모델 응답 수신이나 운영 서버 반영의 증거가 아닙니다.

## 화면과 호출 방법

- 기존 화면: `/owner/open-models`
- Chutes 직접 질문 화면: `/owner/open-models/chutes`
- Chutes 목록: `/owner/open-models/chutes/catalog`
- Chutes 호출: `/owner/open-models/chutes/call`
- 프로그램끼리 요청하는 연결 주소(API): `https://llm.chutes.ai/v1/chat/completions`
- 서버 인증 키 설정 이름: `CHUTES_API_KEY`

모든 화면과 호출에는 기존 소유자 인증 및 계열별 사용 제어가 적용됩니다. 같은
Chutes 키 하나로 선택한 모델 하나에만 요청합니다. OpenRouter·DeepSeek 공식 키를
대신 사용하지 않습니다. Chutes 호출이 실패해도 다른 모델이나 제공자로 자동
재시도하지 않습니다. 키 값은 화면·로그·문서에 기록하지 않습니다.

키가 없으면 인증 정보가 필요하다고 표시합니다. 키와 연결 설정을 준비했으면 호출
설정을 마쳤으나 실제 응답을 아직 확인하지 않았다고 표시합니다. 공개 목록 조회,
키 등록, 질문 전송과 실제 응답 수신을 각각 구별합니다. 모델 개발·학습 허용 모음의
설명·개수·동작은 바꾸지 않습니다. 코딩 도구도 같은 Chutes 목록을 읽습니다.

## 9개 제공판과 정확한 호출 식별자

2026-10-17 Chutes 공식 공개 목록의 `id`와 `root`를 대조했습니다. `id`는 실제
요청의 `model`에 보내는 이름이고, `root`는 제공자가 표시한 모델 파일의 이름입니다.
두 값이 다르므로 `root`를 호출 식별자로 보내지 않습니다. FP8은 8비트 수치
형식이며, NVFP4는 NVIDIA의 4비트 수치 형식입니다. `0731`과 `DSpark`는 해당
제공판 이름의 일부이며 생략하지 않습니다.

## 첨부파일과 답변 길이

직접 질문에서 문서·텍스트 파일과 브라우저 음성 받아쓰기를 사용할 수 있습니다.
공개 목록에서 사진 입력을 명시한 Qwen3.6-27B-FP8, Qwen3.5-397B-A17B-FP8,
Qwen3.8-27B-FP8, Gemma-4-31B-IT-NVFP4에만 사진을 전송합니다. 나머지 5개 모델에
사진이 첨부되면 전송하지 않습니다. 공개 목록의 사진 지원과 실제 사진 호출 시험
성공은 별도로 확인해야 합니다. 기존 튜터·문제출제·자료검토는 그대로 남습니다.

글 처리 단위인 토큰의 답변 수를 앱이 기본값으로 정하지 않습니다. 입력란을 비우면
요청에서 `max_tokens`를 생략하여 선택한 제공판의 기본값을 따릅니다. 사용자가 양의
정수를 지정하면 그 값을 보내며 앱 자체의 상한은 두지 않습니다. 모델별 문맥·출력
한도와 제공자 제한은 적용됩니다. 모든 제공판의 기본값이 1,024토큰이라고 주장하거나
필드 생략이 무제한 답변을 뜻한다고 표시하지 않습니다.

## 사용 조건 검토와 범위

모델 파일의 사용허가(라이선스)는 모두 MIT가 아닙니다. 예를 들어
[DeepSeek-V3.2는 MIT](https://huggingface.co/deepseek-ai/DeepSeek-V3.2/blob/main/LICENSE)이며
[Qwen3.6-27B-FP8은 Apache-2.0](https://huggingface.co/Qwen/Qwen3.6-27B-FP8)입니다.
선택한 원본·변환판의 조건과 외부 호출 서비스 계약을 각각 적용해야 합니다.

2026-10-17 확인한 [Chutes 사용 조건](https://chutes.ai/terms)은 2026-03-16 갱신본입니다.
경쟁 모델 개발이나 출력의 모델 학습을 명시적으로 금지하는 조항은 찾지 못했습니다.
이는 검토한 문서에 관한 판단이며 모든 학습 계획에 대한 허가, 제공자의 별도 서면
승인이나 법적 보증으로 표시하지 않습니다. 사용자는 적용 법률·제3자 권리·모델
라이선스를 준수해야 합니다.

사용 조건과 [개인정보 정책](https://chutes.ai/privacy)은 Chutes의 공개 모델 호출에서
입력·응답 내용을 저장하지 않고 자체 모델 학습에 사용하지 않는다고 설명합니다.
과금·운영용 사용 정보는 처리합니다. 이는 제공자 정책의 설명이며 실제 계정과 저장
상태를 독립 검증했다는 뜻은 아닙니다. 하드웨어가 실행 중인 자료를 보호하는 환경(TEE)과
요청의 양 끝에서만 내용을 해독하는 종단 암호화는 다릅니다. 이 앱은 일반 인증 요청에
종단 암호화를 추가 구현하지 않았습니다.

운영 앱과 대량 자동 요청에는 사용량에 따라 과금하는 방식(PAYGO)이 적용됩니다.
이 변경 자체로 새 계정 생성·결제·유료 모델 호출을 수행하지 않습니다. 기존 OpenRouter
경로의 경쟁 모델 개발·학습 허용 여부를 변경하거나 승인하지 않습니다.

인증 정보가 없을 때의 차단, 모델별 사진 지원과 답변 길이 필드 처리를 확인합니다.
