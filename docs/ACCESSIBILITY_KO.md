# 점자판 인식·수어 입력·수어 영상 표시

뉴스·강의 전사 코드집 저장을 먼저 완료한 뒤 추가한 기능입니다. 특허 원문·청구항은 수정하지 않았습니다. 관리자 메뉴와 기존 전사 화면에서 `/owner/accessibility`로 연결합니다. 기존 관리자 로그인과 영속 저장 공간을 재사용합니다.

## 점자판 사진에서 점 배열 읽기

사진 위에서 첫 점의 위치, 점 사이 간격, 칸 사이 간격, 가로·세로 칸 수를 맞추면 6점 또는 8점의 점 배열을 읽습니다. 점 배열을 표현하는 유니코드 점자와 각 점의 관측값·좌표·원본 식별값을 돌려줍니다. 격자를 자동 추정하지 않습니다. 모호한 점이 있는 칸은 대체문자와 미확정 상태로 남깁니다. 명확하게 보이는 자동 결과도 사람이 확인한 판독으로 표시하지 않습니다.

입력은 10MiB·2000만 화소 이하 PNG·JPEG·WEBP·BMP입니다. 사진의 방향 정보를 적용한 뒤 화면과 같은 방향으로 읽습니다. 양각 점자판의 그림자·반사·기울기에 따라 틀릴 수 있습니다. 실제 양각판 사진의 정확도는 아직 측정하지 않았습니다.

점 배열과 한국어 문장 번역은 구분했습니다. 운영자가 확인한 Liblouis 규칙 파일을 `BRAILLE_LIBLOUIS_TABLE`에 지정하고 `lou_translate`가 설치돼 있어야 문장으로 바꾸는 선택 기능을 사용합니다. 규칙 파일이 없으면 한국어를 추측하지 않습니다. 실제 한국어 역번역은 아직 시험하지 않았습니다.

## 수어 입력의 두 경로

외부 경로는 운영자가 지정한 한국수어 인식 제공자에 영상과 모델 식별자·원본 내용 식별값을 보내는 연결 형식입니다. 응답 언어·시간·문장·신뢰값·원본 식별값을 검사하고 자동 결과를 미확정으로 표시합니다. 제공자 주소·모델·인증키와 실제 데이터 처리정책 확인이 없으면 전송하지 않습니다. 이 코드는 특정 제공자가 실제로 해당 형식을 지원한다고 확인한 결과가 아닙니다. 실제 제공자와 검증된 한국수어 모델을 확보해 연결해야 합니다.

로컬 경로는 손 관절 좌표를 읽는 MediaPipe 도구와 검증된 `.task` 모델 파일을 지정한 뒤, 관리자가 이름을 붙여 등록한 동작과 새 영상의 움직임을 비교합니다. 시간 길이가 다른 움직임을 맞춰 비교하는 방법(DTW)을 사용합니다. 비슷한 후보가 없거나 서로 구분하기 어려우면 미확정으로 남깁니다.

손 모양·움직임 비교는 한국수어 문장 전체를 번역하는 기능이 아닙니다. 표정·입 모양·몸 방향·문법을 모두 해석하지 않습니다. 자동 비교의 점수를 실제 한국수어 의미의 정답 확률로 표시하지 않습니다. 로컬 실행에는 `deployment/accessibility/requirements-local-sign.txt`의 선택 도구를 설치하고 운영자가 확인한 모델 파일을 `MEDIA_SIGN_LOCAL_MODEL_PATH`에 지정해야 합니다. 모델 파일은 자동 다운로드하지 않습니다.

수어 입력은 32MiB·60초 이하의 영상입니다. 원본은 요청 처리 뒤 삭제합니다. 외부 실제 인식과 실제 사람 수어 영상의 정확도는 아직 확인하지 못했습니다.

## 수어 영상 등록과 표시

권한이 있는 MP4·WebM 수어 영상을 문구·제목과 함께 등록하면 목록에서 찾아 재생할 수 있습니다. 사용자 동작으로 재생하고, 재생·일시정지·종료·오류 사건과 재생시간·화면 표시 상태를 원본 영상의 내용 식별값에 연결해 기록합니다. 의미를 붙여 등록했다고 전문가 검증이 끝난 것으로 표시하지 않습니다. 재생 사건은 이해·주의집중·학습 효과를 증명하지 않습니다.

영상 보관 공간은 96MiB로 제한합니다. 재생 사건은 최대 1만 건·30일까지 보존합니다. 영상은 관리자가 삭제할 수 있습니다. 시청자 개인정보를 새로 수집하는 항목은 넣지 않았습니다. 원본 영상의 사용 권한은 업로더가 확인해야 합니다. 외부 사전의 영상을 자동으로 내려받거나 다시 공개하는 코드는 넣지 않았습니다.

## 운영 설정과 검사 범위

Railway에서 기존 공식 서비스의 설정 파일 경로를 `/deployment/accessibility/railway.json`으로 지정하면 전사 기능의 도구와 Liblouis를 함께 설치하도록 준비했습니다. 로컬 손 좌표 모델을 사용할 경우에만 준비 단계의 `INSTALL_LOCAL_SIGN=true` 옵션으로 MediaPipe를 추가 설치하십시오. 모델 원본은 이 설치 과정에 포함하지 않았습니다. 실제 이미지 준비와 서버 반영은 아직 하지 못했습니다.

`deployment/accessibility/accessibility.env.example`에 설정 이름을 보존했습니다. 인증키를 16진수로 바꾸거나 길이를 강제하지 않습니다. 실제 요청·응답 무보관 정책은 제공자의 해당 유료 계정·제품·주소에서 확인해야 합니다. 확인 설정은 제공자의 정책 자체를 증명하지 않습니다.

생성한 점자 이미지의 모든 6점·8점 배열, 노이즈·부분 점·방향·크기 조건을 검사했습니다. 합성한 손 좌표로 등록 동작 비교·알 수 없는 동작·모호한 후보를 검사했습니다. 외부 응답과 MediaPipe 결과를 대체해 검사한 부분은 실제 사람 수어 인식으로 보고하지 않습니다. 실제 영상 변환·파일 등록·재생 요청·기록 저장은 별도 검사 기록을 따릅니다.
