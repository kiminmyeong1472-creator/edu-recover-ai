# 딥시크 직접 호출

Railway 운영 서비스에서 `EDURECOVER_DEEPSEEK_DIRECT_ENABLED=true`를 설정하면 다음 두 모델을 딥시크 공식 API로 직접 요청합니다.

| 화면 모델 | 공식 호출 이름 |
|---|---|
| DeepSeek-V4.1-Flash | deepseek-flash |
| DeepSeek-V4-Pro | deepseek-v4-pro |

서버에 `DEEPSEEK_API_KEY`가 있어야 합니다. 인증 키는 Railway 비밀 환경변수에만 저장하며 문서, 코드, 사용자 입력창, 응답에는 넣지 않습니다. `OPENROUTER_API_KEY`는 딥시크의 인증 키를 대신하지 않습니다.

직접 연결을 켜면 기존 두 모델의 연결을 공식 직접 경로로 바꾸고, 다른 딥시크 모델의 OpenRouter 경유 연결을 제외합니다. 나머지 계열의 연결은 보존합니다. 이전 R1/V3.2/V4 Flash를 새 Flash와 같은 모델로 바꾸어 표시하지 않습니다.

이 두 직접 경로에는 무보관 조건(ZDR)을 요구하지 않습니다. 딥시크의 보관·처리 조건이 적용됩니다. GPT-6 Luna는 기존 Azure 경유·무보관 필수·우회 금지 조건을 유지합니다. 소유자 로그인과 제공자 사용 허용은 모든 호출에 계속 적용됩니다.

운영 화면은 `/owner/open-models`이며, `/owner/open-models/call`로 직접 질문을 보냅니다. 화면의 인증 정보 필요/호출 설정됨 상태는 서버 설정을 나타내며 실제 호출 성공과 구별합니다. 서버 인증 키를 연결한 후 소유자가 짧은 시험 질문을 보내 실제 응답을 확인해야 합니다.

## 직접 질문의 답변 길이·첨부·음성

직접 질문은 앱에서 `max_tokens`를 지정하지 않습니다. 기존 512토큰 기본값과 화면 입력란을 제거했으며, 제공자 자체의 기본 출력 길이와 문맥 한도는 적용됩니다. 내부 추론 설정은 제공자의 기본 동작을 유지합니다. 길이 한도에 도달해 잘린 답변은 완성된 답변으로 표시하지 않고 구별된 오류를 반환합니다. 제공자의 잔액 부족(HTTP 402)도 다른 요청 거절과 구별합니다. 자동 재시도·다른 모델로 우회 호출은 없습니다.

질문 4,000자, 원문 한 건 16,000자·합계 48,000자, 튜터 대화 12개·합계 16,000자처럼 앱에서 임의로 정했던 입력 제한을 없앴습니다. 질문·원문·이전 대화의 공백과 줄바꿈을 보존하며 오래된 대화나 답변을 조용히 잘라 보내지 않습니다. 서버 자원을 보호하기 위한 HTTP 요청 한도 48MiB와 모델 제공자의 실제 문맥 한도는 계속 적용됩니다. 한도 초과 시 일부만 보내지 않고 오류를 표시합니다. 연결 설정 JSON의 별도 4MiB 한도, 원문 수 8개, 생성 문항 수 10개, 구조화된 초안 응답의 형식 검사는 유지합니다.

운영 서버가 시작될 때 공식 직접 모델 두 개와 Chutes의 별도 딥시크 제공판에 대해 화면 경로별 연결 준비 상태와 소유자의 사용 허용 상태를 기록합니다. 이 검사는 외부 요청을 보내지 않으며 실제 호출 성공을 뜻하지 않습니다. 호출 실패 기록도 등록된 모델 이름·화면 경로·고정 오류 코드만 남깁니다. 인증 키, 질문, 답변, 원문 오류 메시지는 기록하지 않습니다. 인증 키 앞뒤에 붙은 공백은 제거하지만 내부 공백·줄바꿈이나 헤더 삽입 문자는 거부합니다. 기존 사용 보류·차단·검증 전용 정책은 계속 적용됩니다.

직접 질문에 사진·문서·텍스트·코드 파일을 한 번에 최대 4개, 각 8MiB까지 첨부할 수 있습니다. 파일은 메모리에서 검사·처리하며 서버 디스크에 저장하지 않습니다. TXT·MD·CSV·JSON·PY·JS·HTML·CSS·YAML, 텍스트를 추출할 수 있는 PDF와 DOCX는 원문을 구분해서 질문에 넣습니다. 암호화된 PDF·글자를 추출할 수 없는 스캔 PDF·지원하지 않는 형식은 모델을 호출하기 전에 이유를 표시합니다. 파일 처리에 필요한 크기·페이지·압축 해제 한도는 적용합니다.

사진(PNG·JPEG·WebP)은 공식적으로 사진 입력을 지원하는 `deepseek-flash` 직접 연결에만 전송합니다. `deepseek-v4-pro` 등 사진 입력을 연결하지 않은 경로는 사진을 첨부하면 호출 전에 안내합니다. 사진을 임의의 외부 주소로 업로드하거나 인증 키를 브라우저에 전달하지 않습니다.

마이크 음성 입력은 브라우저의 한국어 음성 인식으로 질문창에 문자를 넣습니다. 자동으로 질문을 전송하지 않습니다. 브라우저 지원과 마이크 허용이 필요하며, 브라우저 제공업체의 서버를 통해 음성을 인식할 수 있습니다. 녹음 파일 업로드·서버 음성 전사는 이 기능에 포함되지 않습니다.

브라우저가 음성 인식을 지원하지 않거나 초기화에 실패하면 질문창으로 이동해 휴대폰 키보드의 마이크를 사용할 수 있도록 안내합니다. 키보드 마이크는 사용자가 직접 선택해야 하며, 브라우저 음성 기능의 실패 때문에 모델 목록이나 질문 전송이 멈추지 않도록 처리합니다. 휴대폰 실제 음성 인식과 딥시크의 실제 응답 수신은 별도 확인이 필요합니다.
