# EduRecover 영업비밀형 출제자료 운영정책

기준일: 2026-09-26

## 1. 기본 원칙

EduRecover는 Google Drive 전체를 외부 AI에게 전송하지 않는다. 서버에 반입하는 자료도 사용자가 승인한 출제·검증용 자산만 화이트리스트로 관리한다.

현재 대화에 업로드된 `SHA256SUMS_암호해제본_20260920.txt`와 `00_암호해제본_읽기안내_20260920.txt`는 전체 Google Drive 자료 자체가 아니라 백업 조각·복구본의 무결성 및 복구방법을 설명하는 인덱스 자료이다. 따라서 이를 전체 출제자료라고 간주하지 않는다.

## 2. 서버 반입 게이트

서버 반입 전 각 자산에 대하여 다음 메타데이터를 만든다.

- source_file_id
- source_title
- MIME/형식
- size
- modified_at
- SHA-256
- source_revision 또는 version
- 용도(출제/검증/구문/어휘/오답/교육과정)
- 공개등급
- 외부 AI 전달 허용여부
- task_excerpt_policy
- 폐기/대체 여부

파일 내용이 바뀌면 새 revision으로 등록하고 기존 revision은 감사이력으로 남긴다.

## 3. 외부 AI 최소전달

외부 AI에는 전체 원본 저장소가 아니라 현재 작업에 필요한 최소 발췌만 보낸다.

예:
- 출제할 본문
- 해당 학년의 구문범위
- 본문에서 실제 매칭된 어휘 항목
- 요청 문항유형에 필요한 출제규칙
- 해당 문항에 필요한 오답설계 규칙

전송 금지:
- 플랫폼 채팅 전체
- 다른 고객 자료
- API 키·토큰·비밀번호
- 전체 내부 로그
- 현재 작업과 무관한 특허·영업비밀 원문
- 전체 내부 출제 코퍼스

## 4. 공급자 경계

공급자별 API 키는 Railway 서버 환경변수 또는 사용자 소유 비밀저장소에만 둔다. 키 실제값은 모델 프롬프트, Google Drive 일반문서, 상태 API, 검증로그에 기록하지 않는다.

공급자 호출은 owner control gate를 통과해야 하며, 공급자는 ALLOWED / RESTRICTED_VERIFY_ONLY / BLOCKED / HOLD 중 하나의 상태로 제어될 수 있다. 이 상태는 AI 자동실행에만 적용하고 사람 사용자의 플랫폼 접근을 자동 차단하지 않는다.

## 5. 검증·배포

AI 생성물은 공급자 이름이나 모델 신뢰도만으로 승인하지 않는다. 문항 상태, 원자료 근거, 검증결과, 교사승인을 분리하며 검증대상 상태와 출력 상태가 동일한지 확인한다.

## 6. 현재 상태

현재 repository에는 출제용으로 선별된 정규화 어휘, 학년별 구문난도, 구문집, 영어 출제규칙, 출제마법사 기준, 오답선지 원리, 현행정책 및 일부 검증된 학년별 어휘가 서버 전용 자산으로 들어 있다.

Google Drive 전체 자료의 완전한 서버 반입은 확인되지 않았으며, 이를 완료로 표시하지 않는다. 앞으로도 전체 Drive 복제보다 출제자산 화이트리스트·해시·버전·최소발췌 전달 방식을 기본으로 한다.
