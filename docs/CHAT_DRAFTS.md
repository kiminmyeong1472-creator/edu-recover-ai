# 전송하지 않은 질문 보관

질문 입력창에 쓰던 문장을 같은 브라우저에 즉시 보관합니다. 다른 화면이나 앱으로 이동한 뒤 같은 질문 화면을 다시 열면 문장을 복원하며 자동으로 전송하지 않습니다.

## 적용 화면

- `/owner/open-models`: 기존 모델 질문·튜터·문제 생성 화면
- `/owner/open-models/chutes`: Chutes 제공판 전용 질문 화면
- `/owner/open-models/learning`: 자체 모델 개발·학습 허용 모델 질문 화면

화면별로 별도의 문장을 보관합니다. 같은 화면에서 모델·분야·작업을 바꿀 때에는 작성 중 문장을 유지합니다. 관리자 이름을 해시로 바꾼 값으로 저장 공간을 구분하며 비밀번호와 인증키를 저장하지 않습니다.

## 저장·복원과 삭제

문자 입력, 한글 조합 완료, 음성 인식 결과 갱신, 화면 숨김과 화면 이탈 때 보관을 시도합니다. 모델 답변을 정상 수신한 경우 전송한 문장을 지웁니다. 요청에 실패하면 문장을 유지합니다. ‘작성 중 문장 지우기’ 또는 새 튜터 대화를 시작하는 동작도 해당 문장을 지웁니다.

다른 탭에서 더 새롭게 작성한 문장은 이전 탭의 전송 완료나 화면 이탈로 덮어쓰지 않습니다. 브라우저가 저장을 막거나 저장 용량이 부족하면 경고를 표시하고 현재 화면의 문장을 메모리에 유지합니다. 저장에 실패한 상태에서는 창을 닫아도 남는다고 표시하지 않습니다.

첨부파일, 이미 전송한 대화 이력, 로그인 정보는 이 기능으로 보관하지 않습니다. 다른 기기나 다른 브라우저로 문장을 옮기는 기능은 포함하지 않습니다. 브라우저의 사이트 데이터 삭제, 시크릿 모드 종료 또는 강제 종료 전에 저장이 실패한 경우 문장을 복원하지 못할 수 있습니다. 저장 문장은 암호화하지 않으므로 같은 브라우저를 공유할 때에는 직접 지우십시오.

## 코드와 확인 방법

- `app/services/chat_drafts.py`: 브라우저 저장 공간 읽기·쓰기, 실패 표시, 다른 탭과의 충돌 방지
- `app/services/open_model_workspace.py`: 실제 질문 화면에서 저장·복원 시점 연결
- `tests/test_chat_drafts.py`: 실제 화면 JavaScript와 저장 코드를 Node.js로 실행해 복원·전송 실패·한글 조합·다른 탭 충돌을 검사
- `tests/test_open_model_workspace.py`: 기존 모델 선택·파일·음성 입력 동작을 함께 확인

검사 명령:

```sh
python -m pytest tests/test_chat_drafts.py tests/test_open_model_workspace.py -q
```

Node.js는 화면의 JavaScript를 시험할 때 필요합니다. 이 변경은 운영 서버에 Node.js나 새 Python 패키지를 설치하지 않습니다. 기존 27개 모델과 Chutes 제공판, OpenRouter 경로 및 유료 호출 권한을 변경하지 않습니다.

이 기능은 EduRecover 질문 화면에 적용합니다. ChatGPT 앱 자체의 입력창은 이 저장소에서 수정할 수 없습니다.
