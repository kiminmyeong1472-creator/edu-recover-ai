1. 절대 운영원칙
================================================================
1) 사용자의 허락 없이 AI 회사별 작업비중, 우선순위, 기본 사용정책, 통제정책을 임의로 고정하지 않는다.
2) 실제 저장소를 읽지 않고 읽었다고 말하지 않는다.
3) 실제 배포/실행을 확인하지 않고 완료라고 말하지 않는다.
4) API 키·토큰·비밀번호·복호화키의 실제 값을 채팅, 프롬프트, 일반 문서, 상태 API에 넣지 않는다.
5) 외부 AI에는 플랫폼 채팅기록을 전달하지 않는다.
6) 외부 AI에는 전체 영업비밀/전체 코퍼스를 보내지 않고 현재 출제·검증 작업에 필요한 최소 발췌만 보낸다.
7) 출제자료/출제지침에서 특정 외부 AI 회사나 모델 출처를 유추할 수 있는 표시는 런타임 자료에서 중립화한다.
8) 사람 사용자가 최종 통제권자이며 AI 통제는 AI 공급자의 자동실행·라우팅·검증·도구권한에 한정한다.

6. AI 회사별 경로 분리 및 게이트
================================================================
통제 코드:
- app/services/control_plane.py
- app/services/privacy_guard.py
- app/services/access_notice.py
생성 채널:
- /channel/openai/generate
- /channel/gemini/generate
- /channel/claude/generate
검증 채널:
- /channel/openai/verify
- /channel/gemini/verify
- /channel/claude/verify
레거시 공용 endpoint:
- /generate-questions → 410
- /verify-with-provider → 410
즉 외부 AI 회사별 경로를 분리한 상태.
owner/provider gate:
- provider가 owner allow-list에 없으면 OWNER_PERMISSION_REQUIRED
- block list면 BLOCKED
- restricted provider가 generate 시도하면 RESTRICTED_VERIFY_ONLY
- 전체 AI HOLD 가능
- AI 통제상태로 사람 owner를 자동 차단하지 않는다.
현재 Railway 환경에서 확인된 통제 변수 이름:
- EDURECOVER_ALLOWED_PROVIDERS
- EDURECOVER_REQUIRE_CROSS_VERIFICATION
- EDURECOVER_REQUIRE_EXPLICIT_PROVIDER_ALLOW
- EDURECOVER_REQUIRE_ZDR
- OPENAI_MODEL
- 기타 Railway/환경 변수
주의: 최신 직접 조회에서는 실제 AI API key 변수 이름은 보이지 않았다. 외부 호출 전 반드시 실제 서비스 Variables에서 다시 확인한다. 키 실제값을 채팅으로 요구하지 않는다.

7. 외부 AI 출입공지/격리/퇴출
================================================================
모든 외부 AI 호출에 app/services/access_notice.py의 공지가 붙도록 구현:
- 현재 라우팅된 작업만 허용
- 플랫폼 채팅기록, API 키, 자격증명, 내부로그, 다른 회사 채널, 무관 고객자료 접근 금지
- cross-provider state, persistent memory, hidden cache, background task, out-of-band callback 금지
- owner/router/privacy gate 우회 금지
- 위반 탐지 시 HOLD, quarantine, channel revocation, evidence preservation, provider removal 가능
- 계약상/법적 구제수단을 취할 수 있음을 통지하되, 공지 자체가 법적 책임을 확정하지는 않음

8. ZDR / 외부 AI 데이터 보존 통제
================================================================
app/services/privacy_guard.py
- 기본: EDURECOVER_REQUIRE_ZDR=true
- provider-side ZDR/retention coverage가 확인되지 않은 채널은 fail-closed HOLD
- 각 AI 회사마다 ZDR confirmed flag + basis 기록이 둘 다 있어야 privacy gate 통과
- 앱 내부 store=false/stateless 호출만으로 provider-side ZDR을 보장한다고 주장하지 않는다.
- 실제 조직/프로젝트/엔드포인트/모델에 대한 공급자 측 Zero Data Retention 설정·승인·계약 적용 여부가 별도로 확인되어야 한다.
- platform_chat_history_forwarded = false
- provider_calls_are_stateless = true
중요 미완료:
- OpenAI/Google/Anthropic 측 조직·프로젝트 수준 실제 ZDR 계약/승인/설정 상태를 플랫폼 코드만으로 완료했다고 주장할 수 없음.
- 실제 공급자 관리자 페이지/계약 수준 확인 후에만 해당 confirmed flag를 true로 설정.
