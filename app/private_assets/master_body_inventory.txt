3.1 국내 공식 평가 이론
  3.1.1 오답지 매력도 제고 6원칙(검증됨)
    ① 학생이 흔히 범하는 오류 이용 ② 사실처럼 보이는 교재 용어 사용
    ③ 부주의하기 쉬운 내용 ④ 정답지와 유사한 내용
    ⑤ 길이·어휘·구문 수준을 정답과 비슷하게 ⑥ 옳지만 문두와 무관한 내용
  3.1.2 답지 배열 규범: 상호 독립, 중복 금지, 같은 단어 반복 금지, 비슷한 길이(다를 경우 짧은 것→긴 것), 논리적 배열, "모든 것이 정답" 제한
  3.1.3 난이도 조절 기제: "답지의 내용과 표현을 아주 비슷하게 만들어 동질성을 높임" — 고난도의 정체는 어려운 지문이 아니라 동질성 높은 답지
  3.1.4 사후 분석: 국가수준 학업성취도평가에서 정답률·변별도·오답매력도 분석 실시
  3.1.5 교육청 학평 자료에도 "답지 매력도 분석하여 난이도 조절" 명문화


3.2 학술 연구 (ADG, Automatic Distractor Generation)
  3.2.1 체계적 문헌고찰: 2009~2024년 60편 확인, 트랜스포머가 주류
  3.2.2 클로즈형 계열: CDGP(EMNLP 2022), KL 규제 Text2Text(ACL 2023), 지식그래프 기반(ACL 2024)
  3.2.3 수학·오개념 계열: Feng 외(NAACL 2024 Findings), Scarlatos 외 overgenerate-and-rank(BEA 2024), DiVERT(EMNLP 2024)
  3.2.4 ★핵심 논문: 서울대·Elice, arXiv 2501.13125
    - 학생 선택률 기반 pairwise ranker 학습 → DPO로 오답 생성기 훈련
    - 순위 예측 정확도 67.5%(GPT-4o 64.0%), 교수 2인 71.7%
    - 변별도 지수 DI 0.212 (수용 범위 0.21~0.24)
    - 한국 고교 영어 시험 88문항으로 학습·실험 포함
    - 부정형 발문에서 LLM 타당도 붕괴 → 유형(T) 선언으로 개선
  3.2.5 국내 영어 시험 오답 반응 연구: 687명 문법시험 분석, 유의미 유인 오답으로 16개 문항 구인 재정의 필요 → 과유인 경계
  3.2.6 빈칸 유형이 오답률 최상위(EBSi 상위 1·2·3·5위)


3.3 업로드 문서(Gemini 생성)의 허위 사실 적발
  3.3.1 뤼이드 KR10-2244249/10-2342371, 매스프레소 KR10-2317926/10-2384912 및 "구성 1~4" 청구항 문언 = 전부 환각(존재하지 않음). Gemini 본인이 시인함.
  3.3.2 효과 데이터(복수정답 18.5%→0.4%, DI 0.14→0.29) = 가짜 수치. 명세서 기재 시 무효사유.
  3.3.3 "ACL 2026" 표기 = 불가능한 연도
  3.3.4 "KIPRIS 보안으로 청구항 전문 추출 불가" = 사실 아님. 구글 특허로 확보 가능(실제 7건 확보함)


3.4 실행 체크리스트(문항 제작 시 적용)
  3.4.1 유형(T) 먼저 선언 — 긍정형/부정형 판정 후 생성
  3.4.2 오답 4종 역할 분담 — 소재중복+결론반대 / 과잉일반화 / 지엽적세부 / 인과전도
  3.4.3 표면 통일성 — 단어 수 ±2, 동일 문법 구조, 정답이 최장 아님
  3.4.4 정답 근거 1문장 고정 + 상위어 치환
  3.4.5 복수정답 차단 — 각 오답의 모순 지점 1개씩 기재, 못 쓰면 폐기
  3.4.6 사후 지표 — 반응분포·DI로 매력도 0 선지 교체
  3.4.7 과유인 경계 — 상위권은 정답, 중하위권만 특정 오답에 몰리는 형태

  4.2.2 유형별 오답 규범 + 마크업 규격 + 결정론적 검증기
  4.2.3 어법 포인트 6종: 수일치·관계사·태·준동사·병렬·대명사
  4.2.4 자체 테스트 15/15 통과
    차단 확인: 어법 오류2개·표지4개 / 순서 배열-정답번호 불일치·단서누락 / 지칭 3:2구조 / 요약 (A)공유오답 없음 / 빈칸 정답최장·중복


4.3 parsers.py — 순서배열·어법 파서
  4.3.1 ★치명적 결함 수정: 업로드 코드는 원문순서를 그대로 A→B→C로 라벨링 → 정답이 항상 "A-B-C"인데 수능 5지선다에 A-B-C가 없어 문항 불성립 → 라벨 재배정(첫 단락에 A 배제) 구현
  4.3.2 그 외 수정: cut_candidates 인덱스 2칸 어긋남, 빈 단락 발생, random.sample 카테고리 편중
  4.3.3 순서: 절단점 조합 중 길이 편차 최소 선택, 2·3단락 연결단서 필수, 없으면 REJECT
  4.3.4 어법: 규칙기반 오류형(mutation)까지 제시(is→are, which→what, tuned→tuning, roughly→rough), 대소문자 보존
  4.3.5 spaCy 없으면 규칙 폴백


4.4 master.py — 유형 혼합 시험지 컨트롤러
  4.4.1 파서 REJECT 시 빈칸 폴백으로 문항 수 방어
  4.4.2 고정형(어법·순서 등 정답이 지문구조에 묶인 유형)과 가변형 분리
  4.4.3 가변형만 이동시켜 정답번호 균등 + 인접중복 제거
  4.4.4 10문항 드라이런: 순서3/어법3/빈칸4, 정답 각 2개씩, 인접중복 0건, 폴백 1건 정상

23. 6역할 체계 확장 (T2·T3 구현)
═══════════════════════════════════════
23.1 기존 4역할
     Word Salad(소재 중복·결론 반대) / Too Broad(과잉 일반화) /
     Too Narrow(지엽적 세부) / Category Error(인과·범주 전도)
     → 네 역할 모두 '지문 안에서 논리를 비트는' 방식
23.2 추가 2역할
     Outside Knowledge(지문 밖 상식) — 배경지식으로 찍는 학생을 표적. 최대 1개
     Local Coherence(국소 문맥 호응) — 빈칸 앞뒤만 읽는 학생을 표적. 최대 1개
23.3 채택 상한을 둔 이유: Outside Knowledge가 2개 이상이면 지문을 읽지 않고도 소거 가능해짐
23.4 과다 생성이 12개(4역할×3) → 18개(6역할×3)로 증가

24. NLI 3분류 판정 (역할별 채택 기준 분리)
═══════════════════════════════════════
24.1 문제: 기존 규칙은 "모순 근거를 못 대면 폐기". 새 2역할은 지문과 모순되지 않으므로 전부 폐기됨
24.2 해결: 역할의 conflict 속성에 따라 판정 기준을 분리
     contradiction 계열(4역할) : 모순 점수 ≥ 0.60 AND 충돌 문장 인용 가능
     absent 계열(Outside Knowledge) : 후보의 내용어가 지문에 1개 이하만 등장
     local 계열(Local Coherence) : 역접 표지가 반박하는 쪽 내용과 2단어 이상 중복
     공통 : entailment(지문이 뒷받침) → 즉시 폐기 (복수정답 위험)
24.3 검증: 7개 판정 사례 전부 의도대로 채택/폐기
24.4 발견한 버그: Local Coherence 탐지에서 역접 표지 '앞'만 보도록 짰으나,
     "While designers claim X, evidence suggests otherwise" 형태에서는 반박 대상이
     While 뒤 양보절임. 양보절과 역접 앞 문장을 모두 보도록 수정.

     역할을 고르면 오개념 후보가 자동 제시됨

27. 나머지 선행기술 구현
═══════════════════════════════════════
27.1 P3 선지 길이 오름차순 정렬
     충돌 문제: 길이 정렬 vs 정답 번호 균등 분포
     해결: 길이 편차 ≤2어절이면 정렬이 무의미하므로 정답 배분 우선.
           편차가 크면 "오답 길이를 ±2어절로 재조정 후 재시도" 안내. 억지 정렬 금지
27.2 P10 반의어 치환 사전 — 30쌍 등록. 어휘 유형 오답 생성에 사용
27.3 P11 이항대립 교란 — 대조 접속/구·신/개인·집단/단기·장기 4종 패턴 탐지 후
     주객전도 오답 생성 지시문 자동 작성
27.4 P11 단정 표현 역패턴 — 지문에 all·always·never·only 등이 있으면
     "절대어=오답" 통념을 역이용해 절대 표현을 정답으로 출제할 수 있음을 안내
27.5 P9 의미적 거리 제어 — 어휘 중복률을 대용 지표로 사용(25.2에 통합)

28. 교차 검증 구조 (사용자 제안 → 구현)
═══════════════════════════════════════
28.1 문제: 같은 모델이 자기 결과를 검사하면 판단 오류를 공유함
28.2 해결: 환경 변수로 생성 모델과 검증 모델 분리
     GEN_MODEL / VERIFY_MODEL / CROSS_CHECK=1
28.3 동작: 검증 모델로 1차 판정 후 생성 모델로 2차 판정, 두 결과가 갈리면
     해당 후보를 채택하지 않고 사람 검수로 회부
28.4 출력: 해설지에 "⚑ 검수 필요(교차 검증 불일치): 역할 '선지…' (모델A 0.55 vs 모델B 0.90)"
28.5 효과: 28문항 전부가 아니라 판정이 갈린 문항만 검수하면 됨
28.6 특허 관점: 확인한 선행기술 12건에 없는 구성. 청구항 편입 가치 있음
     ("제1 생성 모델과 학습 데이터가 상이한 제2 검증 모델을 두고, 판정 불일치 문항을
       별도 큐로 분리하는" 취지)

■ T1. 부분적 진실 · 동질성 (Partial Truth)
정의   지문의 핵심 어휘를 그대로 쓰되 인과·주객·결론만 비틀어, 언뜻 사실처럼 보이게 만든다.
전제   지문에 2회 이상 반복되는 핵심 키워드가 있을 것.
절차   ① 반복 키워드 2~3개 추출 → ② 그 키워드를 유지한 문장 골격 작성 →
       ③ 서술어·연결 관계만 반전 → ④ 원문과 충돌하는 문장 1개 특정
검증   충돌 문장을 인용하지 못하면 폐기(복수정답 위험).
적용   빈칸·요지·주제·내용일치 전 유형.
실패   키워드를 너무 많이 넣으면 원문 복사처럼 보여 오히려 정답으로 오인된다. 2~3개가 상한.
핵심   "고난도 문항은 어려운 지문이 아니라 동질성 높은 답지에서 나온다."


■ T2. 옳지만 지문과 무관 (Outside Knowledge)
정의   상식적으로 100% 옳지만 지문에 근거가 없는 진술.
전제   지문 주제와 인접한 '유명한 논점'이 존재할 것. (예: 알고리즘 → 개인정보 침해)
절차   ① 지문 주제의 상위 분야 식별 → ② 그 분야의 통념 중 지문에 없는 것 선택 →
       ③ 지문 어휘를 1개 이하만 섞어 자연스럽게 진술
검증   ★ 이 유형은 지문과 모순되지 않는다. 따라서 모순 검사로는 걸러지지 않는다.
       판정 기준을 "지문에 해당 소재가 단 한 번도 등장하지 않음"으로 바꿔야 한다.
적용   내용일치·요약·빈칸.
제한   ★ 5지선다 중 최대 1개. 2개 이상이면 지문을 안 읽어도 소거가 가능해진다.
표적   배경지식으로 찍는 학생.


■ T3. 국소 문맥 매력도 (Local Coherence / MLM형)
정의   빈칸 앞뒤 문장과는 완벽히 호응하나, 글 전체 논지와는 반대인 선지.
전제   빈칸 직전 문장에 역접(While, However, Yet)이 있을 것. 이것이 함정의 축이다.
절차   ① 빈칸 직전 문장에서 명사구·동사구 추출 → ② 그대로 빈칸에 넣어 문법적으로 완결시킴 →
       ③ 글 전체 논지와 반대 방향인지 확인
검증   국소 호응은 성립하되 전체 논지와 충돌해야 한다. 둘 다 성립하면 복수정답.
적용   빈칸 추론 전용. ★ 빈칸 오답률이 최고인 이유가 이 유형이다.
표적   빈칸 앞뒤만 읽고 고르는 학생.


■ T4. 조건 과장 · 절대 어휘 (Over-generalization)
정의   방향성은 맞으나 정도를 극단화한다. all, always, never, entirely, complete, only.
전제   지문에 한정 조건(some, often, in many cases, harmful effect on X)이 있을 것.
절차   ① 한정 표현 탐지 → ② 절대 표현으로 치환 → ③ 나머지는 원문 유지
검증   지문의 한정 표현을 근거로 인용할 수 있어야 한다.
주의   최근 고난도 문항은 이 스킬을 역이용한다. 지문에 단정적 근거를 숨겨 두고 절대 표현을
       정답으로 출제하여 '절대어 = 오답' 요령을 무력화한다. 우리도 가끔 이 역패턴을 써야 한다.
표적   뉘앙스를 극단으로 비약하는 학생.


■ T5. 부정형 발문 제어 (Negative Stem Control)
정의   "일치하지 않는 것은?"에서 정답은 틀린 진술 1개, 오답은 맞는 진술 4개.
전제   없음. 모든 부정형 문항에 적용.
절차   ① ★생성 전에 유형 태그 선언: <문항 유형: 내용 불일치(부정형) / 정답=틀린 진술 1개>
       ② 맞는 진술 4개를 먼저 작성(패러프레이즈) → ③ 틀린 진술 1개를 인과·순서 반전으로 작성
검증   정답으로 지정한 진술이 실제로 지문과 충돌하는지, 오답 4개가 모두 참인지 개별 확인.
근거   서울대·Elice 연구(arXiv 2501.13125): 부정형에서 LLM 타당도가 붕괴하며, 유형 선언으로 개선됨.
실패   태그 없이 생성하면 AI가 중간에 논리가 꼬여 '맞는 진술'을 정답으로 잡고 그럴듯한 해설까지 붙인다.
핵심   가장 매력적인 틀린 선지는 뚱딴지가 아니라 두 개념의 순서·인과를 슬쩍 뒤바꾼 것.


■ T6. 답지 배열 · 형식 규범 (Surface Uniformity)
정의   길이·구조·어조를 균일하게 맞추고, 다를 경우 짧은 것 → 긴 것 순으로 배열.
기준   영어 선지 단어 수 ±2 / 한국어 선지 어절 수 ±1 / 종결어미 통일 / 시작 품사 일치
절차   ① 정답 선지 단어 수 W 측정 → ② 오답을 W±2로 조정 → ③ 정답이 최장·최단이 되지 않게 확인
       → ④ 길이 오름차순 정렬 → ⑤ 정답 번호 균등 분포와 충돌 시, 길이를 더 균일하게 만들어
       정렬이 무의미해지도록 조정한다
검증   정답 단독 최장·최단이면 폐기. Test-wiseness(내용 모르고 요령으로 찍기) 차단.


□ 6대 기술 통합 체크리스트 (문항 1개당)
  1) 유형 태그를 먼저 선언했는가 (긍정형/부정형)
  2) 오답 4개에 서로 다른 역할이 배정되었는가
  3) 각 오답의 모순 지점 또는 무근거 사유를 1문장으로 적었는가
  4) 정답 근거 문장 1개가 고정되고 상위어로 치환되었는가
  5) 길이·구조·어조가 통일되었는가, 정답이 최장·최단이 아닌가
  6) 상위권 유인 오답과 하위권 유인 오답이 각각 1개 이상 있는가

║ PART 2. 빈칸 추론 — ADG 4역할 템플릿 전면 적용 패턴        ║

■ 2-1. 4역할 정의 (원 명칭 유지)
 Word Salad      지문에 2회 이상 등장한 키워드를 포함하되 전체 주제와 반대되는 결론
 Too Broad       정답과 방향성은 같으나 지문 범위를 넘는 포괄적·추상적 개념
 Too Narrow      핵심 주제가 아닌 지엽적 세부·부차적 예시에만 해당
 Category Error  원인을 묻는데 결과를 서술하는 식으로 인과·범주를 비틂


 ※ 확장 2역할(검증 규칙이 다르므로 별도 관리)
 Outside Knowledge  지문 밖 상식 (모순 없음 → 소재 미등장으로 판정)
 Local Coherence    빈칸 앞뒤 호응하나 전체 논지와 반대 (모순 없음 → 논지 충돌로 판정)


■ 2-2. 표준 프롬프트 (그대로 복사해 쓸 것)


 # Role
 당신은 한국 대학수학능력시험 영어 영역의 최고 수준 출제 위원이다.
 주어진 지문과 정답을 바탕으로 매력적인 오답 선지 4개를 생성하라.


 # Context & Target
 - 지문: [지문 텍스트]
 - 정답: [정답 선지 텍스트]
 - 정답 단어 수: [W]


 # Constraints
 1. 길이·구조 통일: 오답은 정답과 단어 수 ±2, 문법 구조(명사구/동명사구/to부정사구 등) 일치.
 2. 오답 시비 차단: 지문 맥락에서 절대 정답이 될 수 없도록 논리적 결함이 명확할 것.
 3. 함정 패턴 배정:
    - Distractor 1 (Word Salad): 2회 이상 등장한 키워드 포함 + 전체 주제와 반대 결론
    - Distractor 2 (Too Broad): 방향성은 같되 지문 범위를 넘는 포괄적 개념
    - Distractor 3 (Too Narrow): 지엽적 세부·부차 예시만 담기
    - Distractor 4 (Category Error): 원인↔결과 전도


 # Processing Steps (CoT)
 선지를 바로 출력하지 말고, 각 선지를 어떤 논리로 설계했는지 <생각 과정>을 먼저 짧게 서술하라.


 # Output Format
 - Distractor N: [선지] (역할: / 모순 지점: / 예상 유인층: 상위권|중위권|하위권)


■ 2-3. 온도 설정 (단계별 분리 필수)
 STEP 1 근거 추출·상위어 치환   0.2   정확성
 STEP 2 역할별 과다 생성        0.7   창의적 함정
 STEP 3 NLI 역검증·유인층 판정  0.1   논리적 엄밀성
 STEP 4 조립·포맷              결정론적(파이썬)  ← LLM에 맡기지 않는다


■ 2-4. 과다 생성 비율
 역할당 3개씩 총 12개 생성 → 역검증 통과분에서 역할별 1개씩 4개 선별.
 통과율이 50% 아래면 프롬프트에 few-shot 예시를 추가한다.


■ 2-5. 실제 적용 예 (교과서 지문 기준)
 빈칸: "Algorithms organize content based on our previous activities, which means that over time ____."
 정답 ③ our exposure to opposing viewpoints steadily narrows (7)
   근거: "they prevent us from discovering information that offers a different point of view"
   치환: a different point of view → opposing viewpoints / remains narrow → steadily narrows
 ① Word Salad     our previous activities begin to broaden our perspectives (8) 상위권
 ② Category Error our narrow opinions decide which content algorithms collect (8) 상위권
 ④ Too Broad      social media replaces every other source of knowledge (8) 중위권
 ⑤ Too Narrow     posts from our close friends appear at the very top (9) 하위권
 표면: 7~9어절, 정답 7이 최단이나 8이 3개라 단서가 되지 않음. 전 선지 [주어+동사구] 구조.

║ PART 3. 선행기술별 출제원리 추출 (1순위 과제)             ║
╚══════════════════════════════════════════════════════════╝
각 항목: [원리] 무엇을 주장하는가 → [출제 규칙] 문항 제작에 어떻게 옮기는가 → [구현] 현재 상태


■ P1. KICE 계열 — 오답지 매력도 6원칙
 원리   오답은 '틀린 답'이 아니라 '정답을 모르는 학생에게 정답처럼 보이는 것'이어야 한다.
 출제규칙
   R1 학생이 흔히 범하는 오류를 오답으로 만든다 → 오개념 목록을 유형별로 축적할 것
   R2 교재에 나온 용어·표현을 오답에 노출한다 → 지문 키워드를 오답에 의도적으로 배치
   R3 부주의하기 쉬운 지점을 노린다 → 부정어, 한정 조건, 비교 대상
   R4 정답지와 유사한 내용으로 만든다 → 정답과 1개 요소만 다르게
   R5 길이·어휘·구문 수준을 정답과 맞춘다 → T6와 동일
   R6 그 자체는 옳지만 문두와 무관한 내용 → T2와 동일
 구현   R2·R4·R5 구현됨 / R1 미구현(오개념 DB 필요) / R3 부분 / R6 미구현 → 6역할 확장 시 반영


■ P2. KICE 계열 — 답지 동질성으로 난이도 조절
 원리   난이도는 지문이 아니라 답지에서 만든다. 답지의 내용·표현을 비슷하게 할수록 어려워진다.
 출제규칙
   난이도 상: 오답 4개를 정답과 1개 요소만 다르게(같은 소재·같은 구조·결론만 반전)
   난이도 중: 2개 요소 차이
   난이도 하: 소재부터 다른 오답 포함
 구현   미구현. ★ 난이도 조절 다이얼로 상품화 가치가 큼. 교사가 상/중/하를 고르면
        오답과 정답의 '차이 요소 개수'를 조절하는 방식으로 구현 가능.


■ P3. KICE 계열 — 답지 배열 규범
 원리   형식 단서로 정답을 유추하지 못하게 한다.
 출제규칙  상호 독립 / 중복 금지 / 같은 단어 반복 금지 / 길이 오름차순 / 논리적 순서 /
          "모든 것이 정답" 금지
 구현   길이 편차 검사·정답 최장최단 금지·중복 검사 구현 / 오름차순 정렬 미구현


■ P4. 답지 반응분포 · 오답 매력도 분석 (학업성취도평가)
 원리   출제로 끝나지 않는다. 선지별 선택률을 사후 분석해 매력도 0인 선지를 교체한다.
 출제규칙  선지별 선택률 기록 → 0%에 가까운 선지 식별 → 그 선지만 교체 후 재사용
 구현   미구현. ★ 단, 학생 응답 수집은 뤼이드 특허 8건의 관문이므로 법률 검토 전 착수 금지.
        대안: 교사가 수기로 입력하는 방식, 또는 제공만 하고 분석은 하지 않는 구조.


■ P5. 서울대·Elice DPO 연구 (arXiv 2501.13125)
 원리   학생들이 실제로 더 많이 고른 오답이 좋은 오답이다. 선택률로 오답 간 순위를 학습시킨다.
 출제규칙
   S1 오답을 만들 때 '이 오답을 고를 학생 층위'를 함께 판정한다 ← 구현 완료
   S2 상위권 유인 오답이 없으면 변별도가 안 나온다 ← 경고 기능 구현 완료
   S3 부정형 발문은 유형을 먼저 선언한다 ← 구현 완료
   S4 선택률 데이터로 생성기를 재학습한다 ← ★특허 저촉으로 제외
 지표   순위예측 67.5%(GPT-4o 64.0%, 교수 71.7%), DI 0.212(수용범위 0.21~0.24)


■ P6. Overgenerate-and-rank (Scarlatos 외, BEA 2024)
 원리   한 번에 4개를 만들지 말고 많이 만든 뒤 골라낸다.
 출제규칙  역할당 3개씩 12개 생성 → 검증 통과분에서 선별 ← 구현 완료
 확장   선별 기준에 '예상 선택률 순위'를 넣으면 품질이 올라간다. 현재는 역할·길이만 본다.


■ P7. DiVERT (EMNLP 2024)
 원리   오답 뒤에 있는 '오류'를 해석 가능한 텍스트로 명시하면 품질이 올라간다.
        7B 모델로 GPT-4o 기반 방법을 능가.
 출제규칙  오답마다 '어떤 오개념의 산물인지'를 텍스트로 적게 한다 ← 부분 구현(모순 지점은 적으나
          오개념 라벨은 없음). ★ 25종 오답 매뉴얼이 바로 이 오개념 라벨 체계에 해당한다.


■ P8. CDGP / MLM 계열 (EMNLP 2022 등)
 원리   언어모델이 빈칸에 자연스럽다고 예측하는 단어 중 정답이 아닌 것이 좋은 오답이다.
 출제규칙  빈칸 앞뒤 국소 문맥만으로 자연스러운 선지를 일부러 만든다 ← T3와 동일.
 구현   미구현. 6역할 확장 시 Local Coherence 역할로 추가.


■ P9. KL 규제 Text2Text (ACL 2023)
 원리   변별도 요인을 생성 과정에 직접 반영해 오답의 난이도를 제어한다.
 출제규칙  난이도 목표치를 받아 오답과 정답의 의미적 거리를 조절 ← P2와 결합 가능.
 구현   미구현.


■ P10. 지식그래프 기반 (ACL 2024)
 원리   상위어·하위어·반의어를 지식 베이스에서 끌어와 문맥에는 맞고 정답은 아닌 선지를 만든다.
 출제규칙  정답 근거 문장의 핵심어를 상위 개념어로 치환(정답) / 반의어로 치환(어휘 유형 오답)
 구현   상위어 치환 구현 / 반의어 치환은 parsers.py의 규칙 기반 mutation으로 부분 구현


■ P11. 입시기관 — 국어 영역 함정 패턴
 원리   출제 원리를 역분석해 학생에게 소거법을 가르친다. 우리는 그 반대편에서 쓴다.
 출제규칙
   이항대립 교란: A와 B를 설명하는 지문에서 A의 속성에 B의 주어를 붙인다(주객전도)
   범주 이탈: '이유'를 묻는데 '결과'를 서술하되 내용 자체는 지문과 일치시킨다 ← Category Error
   단정적 표현 역이용: 지문에 단정 근거를 숨기고 절대 표현을 정답으로 출제 ← T4 역패턴
 구현   Category Error 구현 / 이항대립 교란 미구현(대립 개념 탐지 필요) / 역패턴 미구현


■ P12. 입시기관 — 영어 영역 함정 패턴
 원리   동일.
 출제규칙
   Word Salad: 3~4회 반복 키워드를 조합해 주제와 반대·무관한 문장 ← 구현 완료
   Too Broad / Too Narrow: 정답 양옆에 범위를 넓힌 선지와 좁힌 선지를 배치 ← 구현 완료
   교묘한 Paraphrasing: 정답에 본문 단어를 절대 그대로 쓰지 않는다 ← 구현 완료
 배치규칙  ★ 주제·제목 유형은 Broad와 Narrow를 반드시 함께 넣는다. 한쪽만 있으면 변별이 약하다.


■ P13. 변별도 지수(DI) 연구
 원리   상위권은 정답을, 중하위권은 특정 오답에 몰리는 구조가 좋은 문항이다.
 출제규칙  오답 4개 중 최소 1개는 상위권 유인, 최소 1개는 하위권 유인으로 설계 ← 구현 완료
 경계   유인이 과하면 측정 구인 자체가 바뀐다(국내 연구: 687명 문법시험에서 16개 문항 구인 재정의).
        → 상위권 유인 오답은 1~2개로 제한한다.
